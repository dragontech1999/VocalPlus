Vocal+ Build Guide

Fix: CMake not found. Install CMake or set CMAKE to its path.
Prepared: June 13, 2026  |  Project: ~/Documents/VocalPlus

What happened

./build.sh runs CMake to generate the Xcode project and compile the JUCE plugins. macOS did not have cmake on your PATH, and the old fallback path (/tmp/cmake-…) was empty or had been cleared after a restart.

What was done for you

  • CMake 3.31.6 was downloaded into the project at:
    ~/Documents/VocalPlus/.tools/cmake-3.31.6-macos-universal/
  • build.sh was updated to use that bundled copy automatically.
  • A helper script was added: scripts/install-cmake.sh
  • Full build completed successfully (Vocal+ AU/VST3 plugins + VocalAir+).

Build commands (after fix)

cd ~/Documents/VocalPlus
./build.sh xcode    # generate Xcode project (first time or after CMakeLists changes)
./build.sh build    # compile, sign, install for Logic Pro
./build.sh logic    # re-sign / reinstall without full rebuild

If the error appears again

Option A — Automatic (recommended)

cd ~/Documents/VocalPlus
chmod +x scripts/install-cmake.sh
./scripts/install-cmake.sh
./build.sh xcode

This re-downloads CMake into .tools/ if it is missing.

Option B — Point build.sh at CMake manually

If you install the official CMake app from https://cmake.org/download/:

export CMAKE="/Applications/CMake.app/Contents/bin/cmake"
cd ~/Documents/VocalPlus
./build.sh xcode

To make that permanent, add the export line to ~/.zshrc and run source ~/.zshrc.

Option C — Homebrew (if you use brew)

brew install cmake
cd ~/Documents/VocalPlus
./build.sh xcode

Verify CMake is found

cd ~/Documents/VocalPlus
./build.sh xcode

You should see Configuring juceaide and Build files have been written to: …/Build — not the CMake error.

Or check the bundled binary directly:

~/Documents/VocalPlus/.tools/cmake-3.31.6-macos-universal/CMake.app/Contents/bin/cmake --version

Search order used by build.sh

OrderLocation
1cmake on your PATH
2~/Documents/VocalPlus/.tools/cmake-3.31.6-macos-universal/…/cmake
3/tmp/cmake-3.31.6-macos-universal/…/cmake
4/Applications/CMake.app/Contents/bin/cmake
5$CMAKE environment variable (you set this)

Logic Pro after building

  1. Quit Logic completely (Cmd+Q).
  2. Open Logic → Settings → Plug-In Manager → Reset & Rescan Selection.
  3. Enable plugins under manufacturer Vocal+.

Requirements reminder

  • macOS 11+ (VocalAir+ needs macOS 12+)
  • Xcode 15+ with an Apple Development certificate
  • CMake 3.22+ (now bundled in .tools/)
